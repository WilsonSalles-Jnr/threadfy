# Java Threading Benchmark

A simple Java project to study multithreading and compare execution times between sequential and concurrent processing.

### Configuration

Adjust the following variables in `Main` to experiment with different workloads:

- `threadfy`: Enables or disables multithreading.
- `primeLimit`: Maximum number to check when counting prime numbers.
- `loopSize`: Number of task executions.
- `threadSize`: Maximum number of concurrent threads.

### Use Case

Demonstrates how multithreading can improve performance when executing multiple CPU-intensive tasks.
